# 群面实验室 GroupLab

> 与三名不同风格的 AI 候选人完成一场无领导小组讨论，并获得基于团队状态变化的影响力报告。

普通模拟面试通常只评价“你答得怎么样”。群面实验室关注另一个问题：**你的发言有没有让团队向前走？**

当前版本提供“实时大模型导演 + 确定性状态机兜底”的混合 MVP。配置 API Key 后，三名 AI 候选人会依据完整讨论动态回应；未配置或接口暂时不可用时，系统会自动切回可复现的演示导演，不中断群面流程。

## 当前核心闭环

1. 阅读群面案例与五个候选方案。
2. 与三名固定行为风格的 AI 候选人讨论。
3. 群体状态机识别用户的协作动作。
4. 共享面板实时更新评价标准、候选方案、核心冲突和共识度。
5. 用户代表小组完成最终陈述。
6. AI 为每轮提取用户原话证据、团队影响和可执行改进动作。
7. 系统生成五维评分、证据化影响时间线和下一轮唯一训练目标。

## 混合导演架构

系统使用一个统一的“群面导演”协调三名候选人，而不是让三个对话请求互相争抢上下文：

- 兼容 OpenAI 格式的模型接口根据案例、团队状态和历史对话生成 1-2 条动态回应；
- JSON Mode 与 Zod 校验保证候选人和发言结构可被前端稳定消费；
- AI 识别建立标准、整合分歧、冲突处理和推动进展等协作行为；
- 本地状态机负责分数限幅、事实过滤、共识度、共享面板与兜底证据；
- 最终陈述单独检查标准、两个方案、核心理由与风险控制；
- 模型失败、超时或未配置密钥时自动使用确定性回应；
- API Key 只存在于服务端环境变量，不发送到浏览器。

## 评分维度

| 维度 | 分值 | 观察内容 |
| --- | ---: | --- |
| 有效贡献 | 25 | 是否提出新信息、判断标准或明确方案 |
| 推动进展 | 25 | 是否帮助团队从发散走向结论 |
| 倾听整合 | 20 | 是否回应并吸收他人的有效观点 |
| 冲突处理 | 15 | 是否让分歧产生信息，而不是变成人际对抗 |
| 结构节奏 | 15 | 是否建立标准、控制时间并清楚总结 |

## 本地运行

环境要求：Node.js 20.9 或更高版本。

```bash
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。

### 启用实时 AI（推荐：阿里云百炼）

复制环境变量示例：

```powershell
Copy-Item .env.example .env.local
```

然后在 `.env.local` 中填写：

```dotenv
AI_PROVIDER=bailian
AI_API_KEY=你的百炼_API_Key
AI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
AI_MODEL=qwen-flash
```

重新运行 `npm run dev`。页面右上角显示“实时 AI”即代表接入成功。不要把真实密钥提交到 GitHub，也不要粘贴到前端代码中。

也可以将 `AI_PROVIDER`、`AI_BASE_URL` 和 `AI_MODEL` 改为 DeepSeek、OpenAI 或其他兼容接口；旧的 `OPENAI_API_KEY` 与 `OPENAI_MODEL` 配置仍然兼容。

```text
src/
  app/                 页面入口与全局样式
    api/director/      服务端大模型导演接口
  components/          群面流程、讨论房间与报告 UI
  lib/
    director.ts        多模型兼容层、候选人导演与证据化评分提示词
    scenario.ts        案例、方案和候选人设定
    engine.ts          意图识别与群体状态机
    scoring.ts         五维报告生成
    engine.test.ts     核心状态机测试
    types.ts           领域类型
```

## 当前取舍

刻意没有加入：

- 语音、视频和数字人；
- 登录、简历和题库广场；
- 多场景管理；
- 三个相互独立且不可控的 Agent；
- 只根据发言次数生成的笼统评分。

第一阶段优先验证一个问题：学生是否能从“团队状态变化”反馈中获得比普通聊天式模拟更有价值的群面训练。

## 下一步

- 访谈参加过群面的学生，修正评分行为标签；
- 用真实用户群面记录校准导演提示词与行为标签；
- 增加真实群面录像标注集，校准评分一致性；
- 增加第二个信息不对称型案例；
- 支持从关键轮次重新训练，而不是整场重来。

## 隐私

当前案例不要求上传简历或真实个人信息。测试和演示请继续使用假名与脱敏数据。任何 API Key 都只应通过服务端环境变量配置；启用模型后，对话内容会发送给你所选择的模型服务商处理。
