# 群面实验室 GroupLab

> 与三名不同风格的 AI 候选人完成一场无领导小组讨论，并获得基于团队状态变化的影响力报告。

普通模拟面试通常只评价“你答得怎么样”。群面实验室关注另一个问题：**你的发言有没有让团队向前走？**

当前版本提供“实时大模型导演 + 确定性状态机兜底”的混合 MVP。配置 API Key 后，三名 AI 候选人会依据完整讨论动态回应；未配置或接口暂时不可用时，系统会自动切回可复现的演示导演，不中断群面流程。

## 当前核心闭环

1. 阅读群面案例与五个候选方案。
2. 与三名固定行为风格的 AI 候选人讨论。
3. 群体状态机识别用户的协作动作。
4. 共享面板实时更新评价标准、候选方案、核心冲突和共识度。
5. 用户代表小组完成最终陈述。
6. 系统生成五维评分、团队影响力时间线和下一轮唯一训练目标。

## 混合导演架构

系统使用一个统一的“群面导演”协调三名候选人，而不是让三个对话请求互相争抢上下文：

- OpenAI Responses API 根据案例、团队状态和历史对话生成 1-2 条动态回应；
- Structured Outputs 保证返回的候选人和发言结构可被前端稳定消费；
- 本地状态机继续负责行为识别、共识度、共享面板与评分证据；
- 模型失败、超时或未配置密钥时自动使用确定性回应；
- API Key 只存在于服务端环境变量，不发送到浏览器。

## 评分维度

| 维度 | 分值 | 观察内容 |
| --- | ---: | --- |
| 有效贡献 | 25 | 是否提出新信息、判断标准或明确方案 |
| 推动进展 | 25 | 是否帮助团队从发散走向结论 |
| 倾听整合 | 20 | 是否回应并吸收他人的有效观点 |
| 冲突处理 | 15 | 是否让分歧产生信息，而不是变成人际对抗 |
| 结构节奏 | 15 | 是否建立标准、控制时间并清楚总结 |

## 本地运行

环境要求：Node.js 20.9 或更高版本。

```bash
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。

### 启用实时 AI

复制环境变量示例：

```powershell
Copy-Item .env.example .env.local
```

然后在 `.env.local` 中填写：

```dotenv
OPENAI_API_KEY=你的_OpenAI_API_Key
OPENAI_MODEL=gpt-5.4-mini
```

重新运行 `npm run dev`。页面右上角显示“实时 AI”即代表接入成功。不要把真实密钥提交到 GitHub，也不要粘贴到前端代码中。

```text

  app/                 页面入口与全局样式
    api/director/      服务端大模型导演接口

  lib/
    director.ts        OpenAI 结构化输出与导演提示词

    engine.ts          意图识别与群体状态机
    scoring.ts         五维报告生成
    engine.test.ts     核心状态机测试
    types.ts           领域类型
```

## 当前取舍

刻意没有加入：

- 语音、视频和数字人；
- 登录、简历和题库广场；
- 多场景管理；
- 三个相互独立且不可控的 Agent；
- 只根据发言次数生成的笼统评分。

第一阶段优先验证一个问题：学生是否能从“团队状态变化”反馈中获得比普通聊天式模拟更有价值的群面训练。

## 下一步

- 增加第二个信息不对称型案例；

## 隐私

当前案例不要求上传简历或真实个人信息。测试和演示请继续使用假名与脱敏数据。模型请求设置为 `store: false`，任何 API Key 都只应通过服务端环境变量配置。
